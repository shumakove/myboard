# Функциональные требования к онлайн-доске

Поведение собрано по открытым страницам популярных продуктов, предоставляющих возможность работать с досками. Требования описывают собственную доску. Названия функций не привязаны к Holst.

Документ содержит только функциональные требования.

## 1. Рамки

Продукт бесплатный. Тарифов, лицензий, оплаты и ограничений, которые у исходного сервиса зависят от платного плана, нет. Неограниченное число досок, таймер, голосование, приватная организация досок и экспорт доступны всем пользователям, которых создал администратор, и всем, кто открыл доску по ссылке.

Клиент один: веб-браузер на компьютере и та же доска в адаптивной вёрстке на телефоне.

В этот документ не входят нефункциональные требования, биллинг, SAML и единый вход, Active Directory, размещение в контуре заказчика, аудит-логи, API-токены, самостоятельная регистрация, вход через Google и Яндекс, приглашение по электронной почте, импорт из Miro, нативные и десктопные приложения.

## 2. Участники

В продукте два способа оказаться в системе.

**Администратор** входит в административную панель. Он создаёт, изменяет и отключает учётные записи. Самостоятельно зарегистрироваться нельзя.

**Пользователь досок** — учётная запись, созданная администратором. Он входит по почте и паролю, ведёт свои доски и выдаёт на них ссылку.

**Участник сессии** — человек без учётной записи. Он открывает доску только по ссылке, указывает имя на эту сессию и работает на доске наравне с остальными. Ссылка действует по модели «все, у кого есть ссылка»: она не привязана к почте и к заранее созданной учётной записи. Отдельных режимов «только просмотр» и «только комментарий» нет.

## 3. Административная панель

| ID | Требование |
| --- | --- |
| ADM-01 | Система должна предоставлять вход в административную панель отдельной учётной записи администратора. |
| ADM-02 | Система должна давать администратору список учётных записей пользователей досок. |
| ADM-03 | Система должна позволять администратору создать учётную запись: имя, адрес электронной почты и пароль. |
| ADM-04 | Система должна позволять администратору изменить имя, адрес электронной почты и пароль существующей учётной записи. После смены пароля все действующие сессии этой учётной записи отзываются. |
| ADM-05 | Система должна позволять администратору отключить учётную запись. Отключённый пользователь не может войти. Его доски сохраняются. |
| ADM-06 | Система должна позволять администратору снова включить отключённую учётную запись. |
| ADM-07 | Система должна отклонять создание второй учётной записи с тем же адресом электронной почты. |

## 11. Сводка границ

Администратор заводит учётные записи. Пользователь досок ведёт доски, папки и шаблоны и выдаёт ссылку. Любой обладатель действующей ссылки входит без регистрации, называет себя и работает на доске вместе с остальными. Перенос доски между установками идёт через файл резервной копии на локальном диске.
