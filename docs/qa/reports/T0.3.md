# T0.3 · QA-отчёт

Требования: — (инфраструктурная задача; проверяются блок «Тестирование» T0.3 в `PLAN.md` и наблюдаемые решения ARCHITECTURE.md, разделы 3, 4, 10, 12)
Коммит сценариев: <заполняется после коммита>

Сценарии составлены только по `PLAN.md` (блоки «Разработка» и «Тестирование» T0.3), `ARCHITECTURE.md` и `CLAUDE.md`, до чтения handoff и кода. Идентификаторы проверок: `ARCH-WEB-*` (маршруты и собранная статика интерфейса), `ARCH-WEBNET-*` (адреса API и WebSocket), `ARCH-WEBDEV-*` (инструменты, проверяемые запуском в ветке DEV).

Роли: в T0.3 ещё нет учётных записей, досок и ссылок, страницы — заглушки. Все проверки выполняются как «посторонний» (браузер без cookie) по `PUBLIC_BASE_URL`, в профилях Playwright `desktop` и `mobile`. Разграничение доступа к страницам по ролям появится в T1.1–T3.1 и здесь не проверяется. Роль «оператор» — тот, кто собирает и проверяет ветку.

Маршруты раздела 4 (далее «все маршруты»): `/login`, `/`, `/boards/{id}`, `/templates`, `/t/{token}`, `/admin/login`, `/admin/users`, `/b/{token}`, `/b/{token}/embed`, `/b/{token}?object={id}`. Для параметров берутся правдоподобные значения: `id` — UUID, `token` — 43 символа URL-безопасного base64 (32 байта) с `-` и `_`.

| ARCH-WEB-01 | посторонний | Позитивный: прямой переход (полная загрузка) на каждый из 10 маршрутов → ответ документа 200 `text/html`, в консоли нет сообщений уровня `error`, нет `pageerror` (необработанных исключений), нет упавших запросов и ответов ≥ 400 | авто (e2e, desktop + mobile) |
| ARCH-WEB-02 | посторонний | Позитивный: на каждом маршруте React смонтировал заглушку — в корневом элементе есть видимый текст (страница не пустая) | авто |
| ARCH-WEB-03 | посторонний | Позитивный: маршруты различимы — заглушки разных страниц показывают разное содержимое (минимум: `/login`, `/`, `/admin/login`, `/admin/users`, `/templates`, `/boards/{id}`, `/t/{token}`, `/b/{token}`, `/b/{token}/embed` не совпадают попарно по тексту); `/b/{token}?object={id}` — та же страница участника, что `/b/{token}` (или её вариант) | авто |
