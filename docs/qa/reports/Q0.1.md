## Состав стенда

| Часть | Где | Что есть |
| --- | --- | --- |
| API | `acceptance/api` (uv, Python 3.12) | pytest + httpx + websockets; фикстуры `base_url`, `clean_stack`, `client`, `two_clients`; заготовки `admin` (T1.1), `board_user` (T1.1, T1.2), `board` (T2.1), `link_participant` (T3.1) |
| E2E | `acceptance/e2e` (pnpm 10, Playwright) | профили `desktop` (1440×900) и `mobile` (Pixel 7, `hasTouch`, `isMobile`); фикстура `twoClients`; заготовки `adminPage`, `boardUserPage`, `board`, `linkParticipantPage` |
| Трассируемость | `docs/qa/traceability.md` | 164 ID из REQUIREMENTS.md, все «не проверено» |

Базовый адрес — только `PUBLIC_BASE_URL`; пустое значение, `localhost`/`127.0.0.1` и не-HTTP схема останавливают прогон с понятной ошибкой. Адрес WebSocket собирается из него (`ws(s)://…/api/ws`). Заготовки фикстур не пропускают тест, а падают с сообщением «появится после T…», чтобы тест на заготовке не выглядел зелёным.

Запуск:

```text
cd acceptance/api && PUBLIC_BASE_URL=http://<IP> uv run pytest
cd acceptance/e2e && pnpm install && pnpm exec playwright install chromium
cd acceptance/e2e && PUBLIC_BASE_URL=http://<IP> pnpm playwright test
```
