Роли: **пользователь досок** (владелец доски, `/boards/{id}`), **участник по ссылке** (`/b/{token}`, на холсте те же права, что у владельца — CVS-07/24/25 проверяются и у него), **посторонний** — для T5.4 закрытых ресурсов нет (новых маршрутов не ожидается; если появятся — проверка отказа постороннему), **администратор** — не затрагивается. Совместная работа (CVS-07) — минимум два независимых клиента (два контекста браузера, либо браузер + WS-клиент).

Границы толкования (фиксирую до чтения handoff):

- **CVS-07** «отменять и повторять действия на доске»: отмена/повтор есть и кнопками (если есть в интерфейсе), и клавишами (CVS-25). Действия: создание, перемещение, изменение размера/свойства, удаление, вставка — каждое отменяется одним Undo и возвращается одним Redo; результат отмены виден второму клиенту (это правка документа). По архитектуре: стек локальный — Undo клиента A не откатывает правки клиента B ни на другом объекте, ни на том же объекте (свойство, изменённое B, остаётся значением B, если A его не трогал); правки, пришедшие от B, в стек A не попадают (A без своих правок нажимает Undo — документ не меняется). Граничные: пустой стек — Undo/Redo ничего не делают и не ломают доску; новая правка после Undo очищает Redo; несколько отмен подряд откатывают в обратном порядке; после перезагрузки страницы стек пуст (локальный), документ не меняется от Undo. Отмена удаления возвращает объект ровно в одном экземпляре с прежним id/свойствами.
- **COL-08 и Undo** (контекст, требование T8.2): если на доске уже есть лента действий/корзина, после отмены удаления восстановленный объект не должен оставаться «удалённым» так, чтобы восстановление из ленты дало дубликат. Если ленты ещё нет — наблюдение для T8.2, не FAIL T5.4.
- **CVS-24** «закрепить набор инструментов на левой панели и менять их порядок. Остальные инструменты доступны из полного списка»: в полном списке видны все инструменты, включая не закреплённые; инструмент можно закрепить (появляется на левой панели) и открепить (исчезает с панели, остаётся в полном списке и выбирается оттуда); порядок закреплённых меняется, и левая панель показывает новый порядок. «Сохраняются» (блок «Тестирование»): после перезагрузки страницы и после повторного открытия доски в той же учётной записи/браузере набор и порядок те же. Граничные: открепить все/оставить один инструмент — интерфейс не ломается (полный список доступен всегда); перемещение первого вверх/последнего вниз — без эффекта. Негативный: изменение набора одним пользователем не меняет панель у другого клиента (это не содержимое доски — наблюдение; если меняет — вопрос владельцу). Мобильный профиль: панель и полный список доступны, цели ≥ 44×44.
- **CVS-25** «горячие клавиши для основных инструментов, отмены, копирования, вставки, удаления, масштаба и перемещения»: каждый инструмент основной панели (закреплённые по умолчанию) выбирается своей клавишей (активный инструмент меняется видимо, `aria-pressed`/выделение); Ctrl/Cmd+Z — отмена, Ctrl/Cmd+Shift+Z (и/или Ctrl+Y) — повтор; Ctrl/Cmd+C и Ctrl/Cmd+V — копия выделенного объекта появляется на доске; Delete/Backspace — удаление выделенного; «+»/«−» (и/или Ctrl+«=»/«−») — масштаб камеры; стрелки — перемещение (вида — по CVS-02; если выделен объект, стрелки двигают объект — оба варианта засчитываются как «перемещение», фиксирую, что именно происходит). Негативные: при вводе текста в поле (переименование, имя участника, редактирование текста объекта, поиск, диалог) клавиши-буквы не переключают инструмент, Backspace/Delete не удаляют объект, Ctrl+Z не откатывает доску вместо текста; Delete без выделения ничего не удаляет. Подсказка с клавишей у инструмента — наблюдение.
- **UI-01 (дополнение)**: цвет текста (`color`) и всех видимых рамок (`border-*-color` при ширине > 0, `outline` в покое) элементов интерфейса на всех экранах — либо строго серый R = G = B (допуск 0), либо акцент/опасный цвет (и их тона), либо белый на акценте. Порог T5.6 (насыщенность HSL ≤ 0,2) заменяется точным равенством каналов. Объекты сцены и цвета участников не проверяются. Фон страницы/панелей — требование говорит о тексте и границах; цветной оттенок фона — наблюдение, не FAIL.
- **BUG-009**: тихие кнопки (`Rename` в списке, `Arrange` в Selection, и любые другие тихие кнопки на экранах) одной высоты; тест с `test.fail` снимает пометку и проходит.
- **UI-03 переключатель** (впервые на экране — ожидается в полном списке инструментов): `role=switch` с `aria-checked`, переключение щелчком и пробелом с клавиатуры, видимые состояния наведения, нажатия, фокуса с клавиатуры и недоступности (если недоступное состояние применяется); вид совпадает во всех местах, где переключатель есть. UI-04: область нажатия ≥ 44×44 на телефоне.
- **Диалоги**: каждый диалог (Share, полный список инструментов, прочие) закрывается одним нажатием Escape; фокус после закрытия не теряется в никуда (наблюдение).
- **Регрессия**: весь `acceptance/` (api + e2e desktop + mobile) без ослабления. Тест, опиравшийся на прежнюю раскладку левой панели, а не на требование, меняется с указанием причины.
