# BUG-028 · Изображение, скопированное на другую доску, не видно участнику этой доски и пропадает после удаления исходной доски

Задача: T7.1   Требование: CVS-20 (копирование между досками) × IMG-01, SHR-04   Серьёзность: major
Коммит: ad6f8c0 (`dev/T7.1`, код 6ade8d6, aa31e72)   Окружение: desktop профиль Playwright; владелец и участник по ссылке второй доски

Шаги (вариант А — участник второй доски):
1. Владелец на доске A загружает изображение (`All tools` → `Image`), выделяет его, Ctrl+C.
2. Открывает свою вторую доску B, щёлкает по холсту, Ctrl+V — на B появилось изображение (у владельца загружено).
3. Участник открывает доску B по её ссылке `/b/{tokenB}` и вводит имя.

Шаги (вариант Б — исходная доска удалена):
1–2. Как выше.
3. Владелец удаляет доску A (`DELETE /api/boards/{A}`) и перезагружает доску B.

Ожидалось (цитата требований): «Система должна копировать, дублировать, вырезать и вставлять объекты на этой доске и между досками пользователя» (CVS-20); у участника по ссылке на холсте те же права, что у владельца (SHR-04, ARCHITECTURE.md раздел 5). Скопированное на доску B изображение — объект доски B: его видят все, у кого есть доступ к B, и оно не зависит от судьбы доски A. По ARCHITECTURE.md раздел 8 файл отдаётся «только при сессии этой доски» и хранится в `MEDIA_ROOT/{board_id}/…`, поэтому файл должен оказаться в `media` доски B (как при создании доски из шаблона — «копирует снимок и файлы в новые идентификаторы», раздел 7).
Фактически:
- А: у участника доски B на месте изображения «Image unavailable» — объект ссылается на файл доски A, `GET /api/media/{id}` с cookie доски B отвечает 404.
- Б: после удаления доски A изображение на доске B не загружается и у владельца (файл удалённой доски — 404).
Handoff T7.1 называет это известным ограничением и относит копирование файлов к T9.1/T10.1, но это задачи шаблонов и резервной копии, а не вставки из буфера; CVS-20 уже принято (T5.3) и с появлением изображений выполняется для них только частично.
Доказательство: `acceptance/e2e/images.spec.ts` — «CVS-20 IMG-01 image copied to another board of the user is shown to a participant by link of that board» (`getByText('Image unavailable')` — 1 элемент у участника B), «CVS-20 IMG-01 image copied to another board survives deletion of the source board» (картинка у владельца не загружена: `naturalWidth` 0). Наблюдение API: `acceptance/api/test_media.py::test_arch_media_other_board_session_refused` (файл доски A с сессией доски B — отказ, что верно для чужого файла).
