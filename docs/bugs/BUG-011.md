# BUG-011 · Рамка текстового блока не следует за текстом после смены размера шрифта и после вставки HTML на холст

Задача: T6.1   Требование: TXT-01 (размер), TXT-08   Серьёзность: minor
Коммит: d8618fe (код 8a049f9)   Окружение: desktop профиль Playwright (1440×900)

Шаги:
1. Инструмент Text, ввести «Several words that wrap onto more lines when large», Escape.
2. В панели `Selection` выбрать `Font size` = 72.
3. Отдельно: скопировать во внешнем редакторе форматированный текст (заголовок, абзацы, вложенный список, ссылка) и вставить на холст вне редактора (Ctrl/⌘+V).

Ожидалось: блок с выбранным размером шрифта (TXT-01) и вставленный с форматированием текст (TXT-08) помещаются в рамку объекта — рамка выделения, маркеры и область щелчка совпадают с видимым текстом.
Фактически: шаг 2 — содержимое 810 px при рамке 98 px (текст далеко ниже рамки, поверх других объектов); шаг 3 — содержимое 268 px при рамке 218 px. Высота пересчитывается только при правке текста в редакторе (известное ограничение handoff).
Доказательство: `acceptance/e2e/text.spec.ts` «TXT-01 TXT-08 BUG-011 block frame follows the text…» (`test.fail`).
Размер и вставка работают, текст виден — поэтому minor.
