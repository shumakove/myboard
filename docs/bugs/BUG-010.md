# BUG-010 · Панель поиска не закрывается Escape, если фокус ушёл с поля

Задача: T5.5   Требование: CVS-08 (UI-03 — единое поведение плавающих панелей и диалогов)   Серьёзность: minor
Коммит: abf6f72 (код 75a5d4c)   Окружение: desktop профиль Playwright (1440×900)

Шаги:
1. Открыть доску с объектами, нажать `Search`, ввести запрос с результатами.
2. Нажать Tab — фокус переходит с поля `Search text and tags` на следующий элемент панели (кнопка результата / `Close`).
3. Нажать Escape.

Ожидалось: панель «Search board» закрывается одним Escape, как Share, All tools и Link to object (так же закрывается и при фокусе в поле). Сценарий зафиксирован в docs/qa/reports/T5.5.md до чтения handoff: «Диалоги/панели закрываются Escape».
Фактически: панель остаётся открытой; Escape закрывает её только при фокусе в поле ввода.
Доказательство: первый прогон `acceptance/e2e/search.spec.ts` «UI-01 UI-03 search panel, object link dialog…» (desktop) — `expect(panel).toBeHidden()` после Tab + Escape: panel visible. Основной тест стиля проверяет Escape из поля (там панель закрывается); фокус на кнопках панели вынесен в отдельный тест «UI-03 BUG-010 search panel closes with Escape when focus is on its button…» с `test.fail` — воспроизводится (результат и `Close`).
Требование CVS-08 выполняется (поиск и переход работают), поэтому minor.
