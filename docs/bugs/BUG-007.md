# BUG-007 · На телефоне панель Selection закрывает верхнюю четверть холста

Задача: T5.3   Требование: MOB-03 (регрессия), CVS-22   Серьёзность: minor
Коммит: a7b98e5 (код 57ce4a4)   Окружение: mobile профиль Playwright (Pixel 7, 412×839)

Шаги:
1. Открыть доску на телефоне, положить два объекта в верхней половине холста.
2. Долгим нажатием выделить один объект.
3. Долгим нажатием на пустом месте у верхнего края холста начать выделение области.

Ожидалось (цитата требования MOB-03): «долгое нажатие начинает выделение» — на любом видимом пустом месте холста.
Фактически: с T5.3 панель «Selection» поверх холста стала в две строки плюс блок «Object info» (кнопки Arrange/Lock/Delete/More, Created/Modified) и закрывает около 23 % высоты холста. Касание в этой зоне попадает в панель, выделение области не начинается. Ниже панели жест работает.
Доказательство: `acceptance/e2e/scene.spec.ts` «MOB-03 a long press selects the object; a long press on empty space…» (mobile) на a7b98e5 падал стабильно (3/3, выделено `['qa-a']` вместо `['qa-a','qa-b']`). На скриншоте `test-failed-1.png` видна панель на верхней части холста. На `main` (T5.2) тест проходил. Тест исправлен: начало жеста опускается под панель (причина записана в отчёте T5.3), после этого 3/3 PASS.

Решение владельца (2026-10-08): исправить в рамках T5.6 (передано при запуске приёмки T5.6).

Исправлен в c5e2d74, проверено (T5.6, проверка 1; регрессия на main @ 298b639).
