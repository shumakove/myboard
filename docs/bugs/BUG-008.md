# BUG-008 · Вставка не учитывает z объектов, записанных в документ JSON-значением

Задача: T5.3   Требование: CVS-20 (ARCHITECTURE.md, раздел 6)   Серьёзность: minor
Коммит: a7b98e5 (код 57ce4a4)   Окружение: desktop профиль Playwright

Шаги:
1. Сторонний клиент пишет в `objects` два объекта обычными JSON-значениями (`{type, x, y, width, height, z: 1}` и `z: 2`), как допускает раздел 6 архитектуры («Объект сцены — JSON с дискриминатором `type`»). Клиент их рисует (ARCH-T52-03).
2. Выделить оба объекта, Ctrl/⌘+C, Ctrl/⌘+V.

Ожидалось: копии ложатся поверх существующих объектов (handoff T5.3: «новые id, поверх»).
Фактически: копии получают `z` 1 и 2, как оригиналы. `topZ` учитывает только значения `Y.Map`, а JSON-объекты пропускает. Копия, вставленная на такой объект, может оказаться под ним. Объекты, которые клиент создаёт сам (`Y.Map`), учитываются правильно: при посеве через `Y.Map` тест проходит.
Доказательство: первый прогон `acceptance/e2e/operations.spec.ts` «CVS-20 ARCH copy, paste…», сообщение `z копий 1, 2; оригиналов {"qa-a":1,"qa-b":2,…:1,…:2}`. Сейчас тест сеет объекты как `Y.Map` (`seedMaps`), так их пишет сам клиент.

Решение владельца (2026-10-08): исправить в рамках T5.6 (передано при запуске приёмки T5.6).

Исправлен в c5e2d74, проверено (T5.6, проверка 1; регрессия на main @ 298b639).
