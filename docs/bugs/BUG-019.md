# BUG-019 · Телефон: поля своего цвета меньше 44×44

Задача: T6.3   Требование: SHP-04 (UI-04)   Серьёзность: minor
Коммит: bb3d0fc (код e3e827f)   Окружение: mobile профиль Playwright (Pixel 7, touch)

Шаги:
1. На телефоне выбрать инструмент `Sticky note` — в палитре `Sticky note color` есть поле `Custom color`.
2. Поставить фигуру, в панели `Selection` нажать `Custom color` — открывается группа с полями `Custom fill`, `Custom border`, `Custom text color`.
3. Измерить поля выбора цвета.

Ожидалось (UI-04): «на телефоне … область нажатия элемента управления — не меньше 44×44 px».
Фактически: каждое поле `input[type="color"]` — 32×24 (в палитре стикеров и в группе `Custom color`). Остальные новые элементы T6.3 (вкладки и кнопки `Shapes`, список `Marker`) — в норме.
Доказательство: `acceptance/e2e/shapes.spec.ts` «UI-04 BUG-019 on a phone the custom color fields … are at least 44x44» (`test.fail`, пока баг открыт); до разделения проверки падал `sticky.spec.ts` «UI-04 MOB-06 … 44x44 targets» (`палитра: 32×24`).
