# BUG-014 · Отмена правки текста после правки другого участника портит общий текст

Задача: T6.1   Требование: CVS-07, COL-01 (ARCHITECTURE.md: «Отмена/повтор — локальный UndoManager, только правки этого клиента»)   Серьёзность: major
Коммит: d8618fe (код 8a049f9)   Окружение: desktop профиль Playwright, два клиента (владелец и участник по ссылке)

Шаги:
1. Владелец создаёт текст «base», Escape.
2. Владелец: `Edit text`, в конец « mine», Escape → у обоих «base mine».
3. Участник: `Edit text`, в начало «theirs », Escape → у обоих «theirs base mine».
4. Владелец снимает выделение и нажимает `Undo`.

Ожидалось: отменяется только правка владельца — у обоих «theirs base» (CVS-07; правки всех участников сохраняются, COL-01).
Фактически: в 3 из 4 прогонов у обоих клиентов и в документе сервера (поздний клиент) — «theirs base minebase»: своя правка не отменена, а слово «base» продублировано; в одном прогоне Undo не изменил текст («theirs base mine»), в одном — отработал верно. Redo возвращает «theirs base mine». С одним клиентом отмена работает верно («base mine» → «base»).
Доказательство: `acceptance/e2e/text.spec.ts` «CVS-07 COL-01 BUG-014 undo after editing a shared text removes only own typing» (падает); ручной разбор с выводом дельты Y.Text у позднего клиента: `[{"insert":"theirs base minebase"}]`.
Порча общего содержимого чужим действием, требование выполняется частично — major.
