# BUG-001 · Ручка перетаскивания на телефоне — 17×24 px

Задача: T2.2   Требование: BRD-10   Серьёзность: minor
Коммит: 6425834   Окружение: mobile профиль Playwright (Pixel 7, 412×839, `hasTouch`)

Шаги:
1. Войти пользователем досок с папкой и доской, открыть `/` в профиле mobile.
2. Измерить кнопку `Drag <название>` у папки и у строки All boards (`boundingBox`).

Ожидалось (цитата требования): «Система должна позволять перетаскиванием менять порядок папок, вкладывать их друг в друга и переносить доски между папками» — на телефоне перетаскивание выполняется пальцем.
Фактически: перетаскивание работает (приёмочные тесты BRD-10 в профиле mobile зелёные, включая автопрокрутку длинного списка), но единственная область захвата — ручка ⠿ размером 17×24 px (в обоих профилях). Это заметно меньше привычной сенсорной цели (около 44×44 px): попасть пальцем трудно, промах начинает прокрутку страницы. Требование выполняется, отклонение — вёрстка.
Доказательство: разовая проверка `boundingBox()` — `{"width":17.125,"height":24}` для `Drag F` и `Drag B` в профиле mobile.
