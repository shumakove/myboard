# BUG-013 · «/» в пустой строке сразу после разделителя не открывает меню вставки

Задача: T6.1   Требование: TXT-04, TXT-06   Серьёзность: minor
Коммит: d8618fe (код 8a049f9)   Окружение: desktop профиль Playwright

Шаги:
1. Создать документ, ввести «Intro», Enter.
2. «/» → `Divider` (после разделителя курсор в новой пустой строке, HTML поля `<p>Intro</p><hr><p><br></p>`).
3. Ввести «/» (и после паузы 1 с — так же).

Ожидалось (TXT-04): «Система должна открывать меню вставки блока по клавише „/“ … в документе».
Фактически: меню не открывается, «/» остаётся текстом (`<p>/</p>`). В следующей строке (после Enter) «/» меню открывает. Воспроизводится стабильно (3 из 3).
Доказательство: `acceptance/e2e/text.spec.ts` «TXT-04 BUG-013 slash on the empty line right after a divider…» (`test.fail`).
Обходится лишней строкой, поэтому minor.
