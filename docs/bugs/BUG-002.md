# BUG-002 · Главная без сессии запрашивает папки и доски до проверки входа

Задача: T2.2   Требование: ACC-04 (раздел 5: список доступен пользователю досок), ARCH-NET-06   Серьёзность: minor
Коммит: 6425834   Окружение: desktop и mobile профили Playwright

Шаги:
1. Без сессии открыть `PUBLIC_BASE_URL/`.
2. Записать ответы с кодом ≥ 400 до `networkidle`.

Ожидалось: страница пользователя без сессии уходит на `/login`, не запрашивая данные списка (так было в T2.1: регрессия ARCH-NET-06 проходила без единого ответа ≥ 400).
Фактически: до перехода на `/login` уходят `GET /api/folders` и `GET /api/boards?sort=title`, оба `401`. Данные не раскрываются (сервер отвечает `401`), вкладка в итоге на `/login` — отклонение не мешает требованиям, но это лишние запросы и красные записи в консоли браузера у анонима. Судя по наблюдаемому поведению, дерево бокового списка загружается независимо от состояния сессии.
Доказательство: `acceptance/e2e/stack.spec.ts` «ARCH-NET-06 …» на коммите 6425834 до правки теста: `["401 …/api/folders", "401 …/api/boards?sort=title"]`. Тест скорректирован (401 от `/api/*` допустим только при итоге на `/login`), см. отчёт T2.2.
