# BUG-025 · Клавиша Delete при выбранном корне интеллект-карты удаляет всю карту

Задача: T6.9   Требование: MAP-02   Серьёзность: minor
Коммит: 8dbbd65 (`dev/T6.9`; в `main` — 43a9373)   Окружение: desktop профиль Playwright

Шаги:
1. Владелец ставит интеллект-карту (клавиша I), добавляет несколько узлов.
2. Щелчком выбирает корень `Main topic` (`data-active="true"`, панель `Mind map` видна; кнопки `Delete node` у корня нет).
3. Нажимает Delete.

Ожидалось (цитата требования): «Система должна добавлять, переименовывать, перекрашивать и удалять узлы…» (MAP-02). Требование не говорит об удалении карты клавишей с выбранным узлом; handoff T6.9 описывает Delete/Backspace как «узел с веткой, карта остаётся; корень не удаляется», а панель у корня не предлагает удаление.
Фактически: карта удаляется целиком вместе со всеми узлами. Данные не теряются: Ctrl+Z возвращает карту со всеми узлами. Поведение непоследовательно с панелью (у корня удаления нет) и с описанием в handoff; пользователь, удаляющий узлы клавишей подряд, может случайно удалить всю карту.
Доказательство: `acceptance/e2e/mindmap.spec.ts` — «MAP-02 negative: … Delete on the root never loses the map» (вывод «наблюдение MAP-02: Delete при выбранном корне — карта удалена целиком»; затем отмена возвращает все узлы).
