# BUG-022 · Щелчок по подписи невыделенной линии выбирает не эту подпись

Задача: T6.4   Требование: CON-03, CON-04   Серьёзность: minor
Коммит: 675fa1a   Окружение: desktop профиль Playwright

Шаги:
1. Провести линию между двумя объектами, добавить подпись `first` (`Add label`), затем двойным щелчком по линии ближе к концу — подпись `second`.
2. Снять выделение (Escape).
3. Один раз щёлкнуть по подписи `first`.

Ожидалось (цитата требования): «Система должна задавать у подписи линии шрифт, размер, цвет и несколько строк» (CON-04), «…ставить на одну линию несколько подписей, двигать их…» (CON-03) — щелчок по подписи выбирает именно её, и группа `Label` панели `Selection` меняет её оформление.
Фактически: линия выделяется, но активной (`data-active="true"`) остаётся прежняя подпись `second`; изменения `Label font`/`Label size`/`Label color` применились бы к ней. Подпись `first` становится активной только после второго щелчка. После перезагрузки первый щелчок не делает активной ни одну подпись. Требование выполняется (подпись можно выбрать вторым щелчком), поэтому minor.
Доказательство: `acceptance/e2e/connectors.spec.ts` — «CON-04 BUG-022 a single click on a label of an unselected line selects that label for editing» (`test.fail`, ветка qa/T6.4).
