# BUG-037 · Встроенный объект с адресом своего сайта получает скриптовый доступ к доске зрителя

Задача: T7.3   Требование: EMB-01, ARCHITECTURE.md раздел 12   Серьёзность: minor
Коммит: 41d13ba (`dev/T7.3`)   Окружение: desktop профиль Playwright

Шаги:
1. Участник встраивает `<iframe src="http://<адрес доски>/b/{token}/embed"></iframe>`.
2. В открывшемся фрейме выполнить `window.parent.document.title`.

Ожидалось: `sandbox` не даёт встроенной странице доступа к доске зрителя.
Фактически: `sandbox="allow-scripts allow-same-origin …"` применяется и к своему адресу, скрипт страницы фрейма получает `document` родителя (`MyBoard`). По спецификации такое сочетание снимает защиту для страницы того же источника.
Серьёзность minor: на своём адресе фрейм разрешает только `/b/{token}/embed`, стороннего скрипта там нет; остальные страницы и файлы во фрейме не открываются (проверено). Способа эксплуатации сейчас нет, это запас на случай будущей уязвимости. Внешние адреса изолированы: родитель недоступен, верхнюю страницу не увести, cookie и адрес с токеном не уходят.
Доказательство: `acceptance/e2e/embed.spec.ts` — `EMB-01 SEC own site inside the frame: closed pages are not shown; the frame has no script access to the board`.
