# BUG-029 · При загрузке файла больше лимита интерфейс пишет про соединение, а не про размер

Задача: T7.2   Требование: FIL-01 (также IMG-01: тот же путь загрузки)   Серьёзность: minor
Коммит: 4af3366 (`dev/T7.2`)   Окружение: desktop профиль Playwright, установленный Chrome (`channel: 'chrome'`), стек `myboard-qa`, `MAX_UPLOAD_BYTES=52428800`

Шаги:
1. Открыть доску, выбрать в `Upload file` файл размером `MAX_UPLOAD_BYTES + 1` байт.
2. Дождаться сообщения на холсте.

Ожидалось: файл отклонён, и участник понимает причину. В интерфейсе для ответа 413 есть текст «The file is too large to upload.».
Фактически: файл отклонён, ярлык не создан (поведение FIL-01 и раздела 8 архитектуры выполнено), но показано «The upload failed. Check the connection.» — участник будет проверять сеть и повторять загрузку.

Причина, видимая снаружи: напрямую (httpx) сервер отвечает 413. Сервер отказывает по `Content-Length`, не читая тело, поэтому браузер, ещё отправляющий файл, получает обрыв, и `fetch` завершается ошибкой сети вместо ответа 413.

Доказательство: `acceptance/e2e/files.spec.ts` — `FIL-01 BUG-029 over-limit message names the size, not the connection` (помечен `test.fail`, снять после исправления); `acceptance/api/test_files.py::test_fil01_file_over_limit_rejected` — 413 при прямом запросе.
