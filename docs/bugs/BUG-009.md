# BUG-009 · Тихие кнопки разной высоты в списке досок и на доске

Задача: T5.6   Требование: UI-03   Серьёзность: minor
Коммит: c12b53a (код c5e2d74)   Окружение: desktop профиль Playwright (1440×900)

Шаги:
1. Открыть список досок `/` с одной доской; кнопка `Rename` в строке доски.
2. Открыть доску, выделить объект; кнопка `Arrange` в панели Selection.
3. Сравнить вычисленные стили двух тихих кнопок (класс одного вида, по handoff — `ghost`).

Ожидалось (цитата UI-03): «Система должна показывать повторяющиеся элементы одинаково на всех экранах: кнопки (основная, второстепенная, опасное действие, кнопка-значок)…».
Фактически: цвет, рамка, скругление, шрифт и тень совпадают, но высота разная — `Rename` 36 px, `Arrange` 32 px. Кнопки панели инструментов холста (44 px) считаю отдельным элементом «плавающая панель инструментов» и в баг не включаю.
Доказательство: `acceptance/e2e/ui.spec.ts` «UI-03 BUG-009 quiet buttons have one height on the list screen and on the board» (помечен `test.fail` до исправления: при исправлении он «неожиданно пройдёт», и пометку нужно снять). Основной тест UI-03 сравнивает тихие кнопки без высоты.
