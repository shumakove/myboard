# BUG-004 · Щелчок или долгое нажатие без движения сдвигает объект к сетке и пишет в документ

Задача: T5.2   Требование: CVS-12 (также CVS-10, MOB-03)   Серьёзность: major
Коммит: d7431ed   Окружение: desktop и mobile профили Playwright

Шаги:
1. Создать фигуру инструментом `Shape`, перетащить её с зажатым Alt на (37, 13) px — положение вне сетки 20 (в документе, например, `x=…77, y=…53`).
2. Щелчком по пустому месту снять выделение, затем простым щелчком (без движения указателя) выделить фигуру снова.
3. Прочитать объект из документа поздним клиентом.

Ожидалось (цитата требования): «Система должна перемещать объекты, в том числе только по горизонтали или вертикали с зажатой клавишей Shift, и временно отключать прилипание отдельной клавишей-модификатором.» — положение, выставленное без прилипания, сохраняется, пока объект не перемещают; выделение щелчком (CVS-10) объект не двигает. По ARCHITECTURE.md выделение идёт в `awareness` и в документ не пишется.
Фактически: после щелчка без движения объект прилипает к сетке: `{x: 77, y: 53}` → `{x: 80, y: 60}` (сдвиг виден всем участникам). То же — у объектов вне сетки, пришедших от другого клиента или поставленных при другом шаге сетки (щелчок по стикеру `x=103, y=107` → `x=100, y=100`), и на телефоне при долгом нажатии без движения (MOB-03: `x=155, y=54` → `160, 60`). Каждый щелчок по объекту, даже уже стоящему на сетке, отправляет кадр `sync Update` (2 щелчка — 2 кадра) — выделение пишет в документ и журнал `board_updates`. Точная расстановка с Alt теряется при первом же выделении объекта, поэтому отключение прилипания действует лишь до следующего щелчка.
Доказательство: `acceptance/e2e/scene.spec.ts` — «CVS-12 CVS-10 a click without movement keeps an object placed off the grid with Alt where it is» (FAIL), «CVS-10 a click selects one object… selection is not written to the document» (FAIL: `syncSent` +2, содержимое документа при объектах на сетке не меняется), «MOB-03 a long press selects the object…» (мягкая проверка FAIL, остальное PASS).
Предложение: при отпускании без перемещения (жест — щелчок/долгое нажатие) не записывать положение и не применять прилипание; писать в документ только при фактическом сдвиге.
