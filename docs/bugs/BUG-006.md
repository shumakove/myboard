# BUG-006 · На телефоне панель инструментов выталкивает холст за первый экран (регрессия T5.1)

Задача: T5.2   Требование: MOB-02 (регрессия T5.1), COL-02…COL-04 на телефоне   Серьёзность: major
Коммит: d7431ed   Окружение: mobile профиль Playwright (Pixel 7, 412×839, touch)

Шаги:
1. Открыть доску на ширине телефона (`/boards/{id}` или `/b/{token}`).
2. Посмотреть, где холст относительно окна.

Ожидалось (цитата требования): MOB-02 «Система должна двигать холст одним пальцем и менять масштаб жестом двумя пальцами.»; на T5.1 (принято) холст на телефоне был в первом экране, и жесты по нему проверялись без прокрутки страницы.
Фактически: левая панель «Tools» на узком экране стала столбцом из пяти кнопок во всю ширину (`{y: 362, height: 236}`), холст начинается на `y = 606` при высоте окна 839: видно 233 px из 505, центр холста и миникарта — ниже окна, страница 1238 px. Чтобы работать с холстом, нужно сначала прокрутить страницу, касаясь вне холста. Принятые в T5.1 приёмочные тесты телефона падают: `camera.spec.ts` (mobile) — 11 тестов (CVS-01, CVS-02 ×2, CVS-04, CVS-05 ×3, ARCH-T51, MOB-02 ×2, COL-04 MOB-02: точки холста вне окна, «страница не отправила курсор»), `presence.spec.ts` (mobile) — COL-02, COL-03, COL-04 (курсор участника не появляется). На desktop те же тесты зелёные.
Доказательство: прогон `acceptance/e2e` на `dev/T5.2` @ d7431ed, профиль mobile; замер: `viewport {"width":412,"height":839}`, `canvas {"x":24,"y":605.9,"width":364,"height":505.4}`, `tools {"x":24,"y":361.9,"width":364,"height":236}`.
Предложение: на узком экране не раскладывать панель инструментов столбцом над холстом (горизонтальная полоса/выпадающий список поверх холста), чтобы холст оставался в первом экране, как в T5.1. Если владелец считает раскладку телефона предметом MOB-01 (T11.1) — ответить вопросом, тогда тесты T5.1 будут дополнены прокруткой к холсту.
