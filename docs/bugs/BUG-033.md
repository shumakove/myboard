# BUG-033 · Страница с неверным адресом изображения даёт 500, карточка ссылки не создаётся

Задача: T7.3   Требование: EMB-02   Серьёзность: major
Коммит: 41d13ba (`dev/T7.3`)   Окружение: `acceptance/api`, desktop профиль Playwright, сайт-образец `acceptance/api/link_site.py`

Шаги:
1. Страница содержит `<title>…</title>` и `<meta property="og:image" content="…">` с адресом одного из видов: управляющий символ `http://linksite:8099/a\x01b.png`; длиннее 65 536 символов; `http://[::1/a.png`.
2. `POST /api/boards/{id}/link-preview {"url": "<адрес страницы>"}` или `All tools` → `Link card` → адрес → `Add card`.

Ожидалось (цитата требования): «Система должна показывать карточку ссылки с названием и изображением страницы и открывать адрес». Изображения нет, название есть, значит карточка с названием и без изображения.
Фактически: `500 Internal Server Error`, карточка не создана. В журнале API: `httpx2.InvalidURL: Invalid non-printable ASCII character in URL`, `httpx2.InvalidURL: URL too long`, `ValueError: Invalid IPv6 URL`. Содержимое чужой страницы управляет ответом сервера: 500 отличает эту страницу от остальных отказов (все остальные — `200` с `null`).
Доказательство: `acceptance/api/test_embed.py::test_emb02_broken_image_address_is_not_a_server_error[/control-img]`, `[/long-img]`, `[/badhost-img]`; `acceptance/e2e/embed.spec.ts` — `EMB-02 page with a broken image address still gives a card with its title`.
