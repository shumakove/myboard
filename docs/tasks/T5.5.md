Подготовка данных (как в T5.3, T5.4):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login` (или форма `/login`), доска — `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.
4. Объекты с текстом — инструментами Sticky note / Shape / Text и Edit text.
5. **Теги**: интерфейса тегов пока нет (STK-03 — T6.2, KBN-02 — T6.8). Формат задан в этой задаче: поле объекта `tags` в `objects` — `Y.Array<string>` (принимается и JSON-массив строк), тег без «#». Для проверки тег пишется клиентом Yjs по `/api/ws` (кадр `sync`/`Update`), например: `objects.get(id).set("tags", Y.Array.from(["urgent"]))`. Так наполнялась доска в smoke-проверке.

Что смотреть:
- **Поиск (CVS-08)** — кнопка `Search` в группе `Board actions` панели `Tools` (`aria-pressed`, пока открыт) открывает плавающую панель `role="search"` «Search board» справа сверху над холстом: поле `Search text and tags` (`type="search"`, фокус сразу). Без учёта регистра, подстрока по тексту объекта и его тегам; запрос с `#` в начале — только по тегам. Счётчик `role="status"`: «N result(s)» или «Nothing found.»; список `Search results` — кнопки: тип объекта, отрывок текста, совпавшие теги `#tag`; порядок — сверху вниз, слева направо. Щелчок по результату или Enter (следующий результат по кругу) — вид переходит к объекту (центр вида — середина объекта, масштаб 100 %, крупный объект — меньше, чтобы поместился) и объект выделен; у текущего результата `aria-current="true"`. Результаты обновляются при правках других участников. Escape в поле или `Close` закрывают панель; клавиши сцены (Delete и др.) в поле не срабатывают.
- **Ссылка на объект (SHR-07)** — при одном выделенном объекте в меню объекта (правый щелчок или `More` панели `Selection`) пункт `Copy link to object` → диалог `Link to object`: поле `Object link` со ссылкой `{PUBLIC_BASE_URL у владельца | адрес страницы у участника}/b/{token}?object={id}` и кнопка `Copy link` (сообщение «Link copied.»), `Close`/Escape. Владелец берёт действующий токен из `GET /api/boards/{id}/share`.
- **Переход по ссылке** — `/b/{token}?object={id}`: после ввода имени (если его ещё нет) и первой сверки документа вид переходит к объекту и выделяет его (вид запоминается, как обычно, CVS-05). Объекта нет — вид не меняется, внизу холста `role="status"` «The linked object is not on this board.» и `Dismiss`. Отозванный или несуществующий токен с `?object=` — тот же отказ «Board unavailable / This link is not available.», канал документа не открывается.

Известные ограничения:
- Интерфейса добавления тегов нет (T6.2, T6.8): по тегам находятся объекты, у которых поле `tags` уже записано в документе.
- Ищется текст объектов, которые есть сейчас (`objects`); объекты в корзине и комментарии не ищутся. Типы T6.* (таблицы, карточки и т. п.) попадут в поиск, если хранят текст в поле `text` и теги в `tags`.
- Пункт «Copy link to object» открывает диалог, а не копирует сразу: без HTTPS копируется выделение поля, а ссылку владельца сначала нужно получить с сервера.
- Ссылка `/boards/{id}?object=…` для владельца не поддерживается — ссылка на объект всегда через токен, как в SHR-07.
