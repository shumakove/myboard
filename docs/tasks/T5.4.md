Переменные — из `deploy/compose/.env.example`. Новых переменных, миграций, npm-зависимостей, HTTP-маршрутов и сообщений WebSocket нет; сервер не менялся.

Подготовка данных (как в T5.3):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login` (или форма `/login`), доска — `POST /api/boards {"title"}` или кнопка New board; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя (или `POST /api/share/{token}/join {"name"}`).
4. Два клиента — две вкладки или два контекста браузера на одной доске.

Что смотреть:
- **Undo/Redo (CVS-07)** — кнопки `Undo`, `Redo` в панели `Tools` (группа `Board actions`), недоступны, пока шага нет; клавиши Ctrl/⌘+Z, Ctrl/⌘+Shift+Z, Ctrl+Y. Отменяются только правки этого клиента: объект/правку второго клиента Undo не трогает; если второй клиент изменил то же поле позже, отмена его значение не перезаписывает. Шаг — одно действие: команда (создание, удаление, вставка, дубликат, группа, слой, блокировка, свойство, фон/сетка), весь жест перетаскивания/размера/поворота, сеанс правки текста. Удаление отменяется (объект возвращается из `trash`). Стек — в памяти вкладки, после перезагрузки пуст. В поле ввода Ctrl/⌘+Z — отмена самого поля.
- **Закреплённые инструменты (CVS-24)** — на панели `Tools` закреплённые инструменты в выбранном порядке (по умолчанию все: Select, Lasso, Sticky note, Shape, Text — как раньше), затем кнопка `All tools`. Она открывает модальный диалог `All tools` (`role="dialog"`): кнопка инструмента выбирает его (работает и для откреплённого) и закрывает диалог; переключатель `Pin <инструмент>` (`role="switch"`) закрепляет/открепляет; `Move <инструмент> up` / `Move <инструмент> down` меняют порядок закреплённых; `Done` или Escape закрывают. Набор и порядок — `localStorage["myboard.pinnedTools"]`, общий для всех досок браузера; сохраняются после перезагрузки.
- **Горячие клавиши (CVS-25)**: инструменты V — Select, L — Lasso, N — Sticky note, S — Shape, T — Text (без модификаторов, в любой раскладке); отмена/повтор — выше; копирование/вырезание/вставка/дубликат — Ctrl/⌘+C, X, V, D (T5.3); удаление — Delete/Backspace (T5.2); масштаб — «+»/«−» (T5.1); перемещение вида — стрелки (T5.1); Escape — снять выделение. Клавиша — в `title` и `aria-keyshortcuts` кнопок. В полях ввода и при открытом модальном диалоге клавиши сцены не срабатывают.
- **UI-01 (дополнение)** — `apps/web/src/ui/theme.css`: `--gray-*` — чистые серые `#f7f7f7 … #1c1c1c` (R = G = B), тени и затемнение `rgb(28 28 28 / …)`; фон страницы `rgb(239, 239, 239)`, текст `rgb(28, 28, 28)`, граница панели `rgb(227, 227, 227)`. Акцент и красный — прежние.
- **BUG-009** — кнопки панели `Selection` 36 px, как тихие кнопки списка досок (Rename); на телефоне — 44 px. Тест `acceptance/e2e/ui.spec.ts` «UI-03 BUG-009 …» с `test.fail` в копии приёмки теперь «неожиданно проходит» — пометку нужно снять.
- Попутно: `Dialog` (`ui/Dialog.tsx`) закрывается по Escape с первого нажатия, даже если тот же Escape перерисовал страницу (до исправления в браузере требовалось второе нажатие).

Известные ограничения:
- Стек отмены — в памяти вкладки, после перезагрузки страницы пуст; удаление, отменённое через Undo, оставляет запись в ленте действий сервера (лента пишется по появлению ключа в `trash`, T4.3).
- Набор закреплённых инструментов хранится в браузере, а не в учётной записи: на другом устройстве — набор по умолчанию.
- Клавиши копирования/вставки сопоставляются по символу (`event.key`, T5.3), а новые клавиши — по коду клавиши; в нелатинской раскладке Ctrl+C/V обрабатывает браузер через события буфера, как и раньше.
