- `docker run` образа `api` без каждой из 7 переменных по очереди — код 1, в stderr `<VAR>: is required`.
- Регрессия T0.1 (`acceptance/api`, только запуск против стека DEV): 46 passed.

Модульные тесты: `uv run pytest` — 28 passed (`tests/test_core.py`: отсутствующая и пустая переменная — по каждой из 7, все сразу, некорректные `MAX_UPLOAD_BYTES` и `PUBLIC_BASE_URL`, флаг `Secure` по схеме адреса, миграции на пустой базе до первого запроса, повторный старт, одна голова ревизий, запрет downgrade, OpenAPI, health, 404 JSON).
Линтеры: `ruff check` — All checks passed; `ruff format --check` — 27 files already formatted; `mypy --strict` — no issues in 27 source files.

Решения: `docs/decisions.md`, раздел «T0.2 · Каркас API» (uv, pydantic-settings, SQLAlchemy 2 async + psycopg 3, Alembic в lifespan, testcontainers, httpx2, ruff/mypy).

Известные ограничения:

- Заглушка `web` (до T0.3) проверяет эхо `/api/ws`, которого больше нет, — её строка «WebSocket» покажет `unreachable`. Заглушка удаляется в T0.3.
- Пустые роутеры модулей не имеют наблюдаемого поведения, поэтому отдельных `test_<module>.py` пока нет; файлы появятся с первыми маршрутами модулей. Инфраструктура покрыта `tests/test_core.py`.
- Smoke через Claude in Chrome не выполнялся: у задачи нет интерфейса, сценарии «Тестирования» — HTTP и запуск процесса, проверены `curl` и `docker run`.
- Если база недоступна при старте, процесс завершается ошибкой lifespan (миграции не применились) — трафик не принимается.
