## Handoff (DEV)

Коммит: последний коммит ветки `dev/T6.9`.
Запуск: `docker compose -p myboard-dev --project-directory deploy/compose down -v`, затем `docker compose -p myboard-dev --project-directory deploy/compose up --build` (переменные — `deploy/compose/.env.example`). Миграций и изменений сервера нет: интеллект-карта — объект документа Yjs, сервер её не интерпретирует.

Подготовка данных (как в T6.1–T6.8):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login`, доска — `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.
4. Инструмент `Mind map` (клавиша **I**) — в `All tools` (можно закрепить, CVS-24); меню пустого места — `Add mind map here`.

Модель данных: карта `type: "mindmap"` — `x`, `y` (середина левого края корня), `z`, `root` (id корня), `nodes` — `Y.Map` id узла → `Y.Map` {`parent` (у корня `null`), `order` (число, порядок братьев), `text` (`Y.Text`), `color`, `collapsed`}. Положения узлов не хранятся — раскладка вычисляется: корень слева, дети правее друг под другом, корень по середине их высоты. Рамка объекта на сцене — по узлам. Новая карта: корень `Main topic` (`#81d4fa`), дети `Idea 1`, `Idea 2`; верх рамки — в точке постановки.

На холсте: карта — `[data-object-id][data-type="mindmap"]` (`aria-label="Mind map"`); узел — `[data-node="<id>"]` (корень — `data-root="true"`, выбранный — `data-active="true"`, при перетаскивании цель — `data-drop="child|before|after"`), пустое название показано как `New idea`; ветки — `svg.mindmap-branches path`; кнопка ветки — `button[data-node-toggle="<id>"]` с именем `Collapse “<название>”` / `Expand “<название>”` (текст — `−` или число скрытых узлов). Пустое место между узлами нажатия не ловит. Маркеров размера у одной выделенной карты нет.

Панель выделения карты (`role="toolbar"` `Selection`), группа `Mind map`: подпись `Node: <название>` (или `Click a node to select it`), кнопки `Add child`, `Add sibling`, `Rename`, список `Node color`, `Collapse`/`Expand`, `Delete node` (без выбранного узла — только `Add child` к корню; у корня нет `Add sibling` и `Delete node`). Поле названия — `textarea` `aria-label="Node title"`. Диалог MAP-04 — `role="dialog"` с именем `Recolor child nodes too?`: текст «“<название>” has N child node(s)…», кнопки `Recolor all`, `Only this node`, `Cancel`.

Известные ограничения:
- Линию (CON-01) можно привязать к карте целиком, но не к отдельному узлу.
- Название узла — одна строка; длинное обрезается многоточием (полностью — в подсказке `title` и в поле правки).
- Раскладка одна — дети справа от родителя.
- Отмена (CVS-07) отменяет правки узлов этого клиента, как у остальных объектов.
