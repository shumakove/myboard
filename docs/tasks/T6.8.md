Ветки: dev/T6.8, qa/T6.8

## Handoff (DEV)

Коммит: последний коммит ветки `dev/T6.8`.
Запуск: `docker compose -p myboard-dev --project-directory deploy/compose down -v`, затем `docker compose -p myboard-dev --project-directory deploy/compose up --build` (переменные — `deploy/compose/.env.example`). Миграций и изменений сервера нет: канбан и карточка — объекты документа Yjs, сервер их не интерпретирует.

Подготовка данных (как в T6.1–T6.7):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login`, доска — `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.
4. Инструменты `Kanban` (клавиша **J**) и `Card` (клавиша **A**) — в `All tools` (можно закрепить, CVS-24); меню пустого места — `Add kanban here`, `Add card here`.

Модель данных: канбан `type: "kanban"` — `x`, `y`, `z`, `height`, `width` (= столбцы × 280), `columns` — `Y.Array` id столбцов, `titles` — `Y.Map` id → `Y.Text` названия. Карточка `type: "card"` — `text` (`Y.Text`), `tags` (`Y.Array` строк), `fill`; в столбце — `parent` = id канбана, `cell` = id столбца, `x`, `y` относительно угла столбца (карточки по порядку: `x` = 20, первая `y` = 48, шаг — высота карточки + 12, ширина 240).

На холсте: канбан — `[data-object-id][data-type="kanban"]` (`aria-label="Kanban"`); столбец — `[data-column="<id>"]` (`data-active="true"` — выбран), заголовок — `[data-column-title="<id>"]` с названием. Карточка — `[data-type="card"]` (`aria-label="Card"`), теги — список `aria-label="Tags"` внизу. Панель выделения канбана (`role="toolbar"` `Selection`): группа `Kanban` — подпись `Column: <название>` (или подсказка выбрать столбец), кнопки `Add card`, `Add column`, `Rename column`, `Delete column` (две последние — при выбранном столбце). Поле названия — `textarea` `aria-label="Column title"`. Диалог удаления — `role="dialog"` с именем `Delete column “<название>”?`: текст «The column has N card(s)…», список `Move cards to`, кнопки `Move cards and delete column`, `Delete column and cards`, `Cancel`.

Пустой столбец удаляется без вопроса; у канбана с одним столбцом `Delete column` нет. У заблокированного канбана столбцы не выбираются и не правятся. |

Известные ограничения:
- Порядок карточек в столбце задаётся только перетаскиванием (сортировки и фильтров по тегам в канбане нет — требованиями не предусмотрены).
- Высота канбана растёт под карточки, но не уменьшается сама; уменьшить за угол можно и ниже карточек (они тогда выходят за нижний край).
- Ширина столбца фиксирована (280); канбан не поворачивается.
- Заблокированная отдельно карточка в столбце при перестановке соседей тоже сдвигается по порядку.
- Сохранение тегов при копировании на другую доску и в резервной копии (KBN-04) — задача T10.1; копирование канбана и карточек с тегами в пределах буфера уже работает (CVS-20).
