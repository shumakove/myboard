## Handoff (DEV)

Коммит: последний коммит ветки `dev/T6.10` (код — 4bf5359).
Запуск: `docker compose -p myboard-dev --project-directory deploy/compose down -v`, затем `docker compose -p myboard-dev --project-directory deploy/compose up --build` (переменные — `deploy/compose/.env.example`). Миграций и изменений сервера нет: комментарии — корень `comments` документа Yjs, сервер его не интерпретирует.

Подготовка данных (как в T6.1–T6.9):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login`, доска — `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.

Модель данных: `comments` — `Y.Map` id ветки → `Y.Map` {`anchor` — `{object, u, v}` (доли рамки объекта без поворота) или `{object: null, x, y}` (точка доски), `color` (`#rrggbb`), `resolved` (bool), `createdAt`, `createdBy`, `messages` — `Y.Array` из `{id, author, text, at}`}. Автор — имя из сессии (владелец — имя учётки, участник — введённое имя).

На холсте и в интерфейсе:
- Начать ветку: инструмент `Comment` (клавиша **O**; в `All tools`, можно закрепить, CVS-24) — щелчок по объекту привязывает к объекту, по пустому месту — к точке; меню объекта — `Add comment` (у правого верхнего угла объекта); меню пустого места — `Add comment here` (на телефоне — долгое нажатие, MOB-03).
- Метка ветки: `button[data-comment-id="<id>"]` в слое доски, `aria-label` «Comment by <автор>[, resolved][, N unread]», текст — число сообщений (у решённой — `✓`), цвет — CSS-переменная `--comment-color`; атрибуты `data-unread="true"`, `data-resolved="true"`. Нижний левый угол метки — в точке привязки. Метка новой ветки до отправки — `[data-comment-draft]`.
- Кнопка `Comments` в группе `Board actions` панели `Tools` открывает панель (`role="region"` `Comments`); при непрочитанных её имя — `Comments, N unread`, рядом число. Панель и поиск (`Search`) занимают одно место — открыта одна. Escape или `Close` закрывают панель.
- Панель, список: группа `Filter by people` (кнопки-переключатели с именами всех авторов, `aria-pressed`), переключатель `Hide resolved`, список `Comment threads` — кнопки `[data-comment-item="<id>"]` (автор, текст первого сообщения, `N new` при непрочитанных — `data-unread="true"`, `Resolved`, число ответов). Щелчок по ветке (в списке или по метке) открывает её и переводит вид к метке.
- Панель, новая ветка: заголовок `New comment`, подпись места (`On <тип объекта>[: текст]` или `On the board`), выбор цвета `Comment color` (`role="radiogroup"`, радиокнопки `Yellow`, `Orange`, `Red`, `Pink`, `Purple`, `Blue`, `Green`, `Gray`), поле `Comment`, кнопки `Post` и `Cancel` (ветка пишется только с первым сообщением).
- Панель, ветка: кнопка `All comments` (назад), `Resolve` / `Reopen`, `Comment color`, список `Messages` (автор, время, текст), поле `Reply` и кнопка `Send`. Enter отправляет, Shift+Enter — новая строка.

Известные ограничения:
- Непрочитанные хранит браузер: в другом браузере или после очистки данных сайта все чужие сообщения снова непрочитаны. Участники с одинаковым именем считаются одним автором.
- Сообщения и ветки не правятся и не удаляются, метку нельзя перетащить на другое место (в требованиях этого нет).
- Отмена (CVS-07) комментарии не затрагивает.
- Метка держит постоянный экранный размер при любом масштабе.
