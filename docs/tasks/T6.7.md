Подготовка данных (как в T6.1–T6.6):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login`, доска — `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.
4. Инструмент `Table` — в `All tools` (можно закрепить, CVS-24), клавиша **B**; щелчок по холсту ставит таблицу 3×3 (столбцы 160, строки 48) центром в точке; меню пустого места — `Add table here`.

Модель данных (`type: "table"`): `x`, `y`, `z`, `width`/`height` (= сумма размеров), `columns` и `rows` — `Y.Array` id; `sizes` — `Y.Map` id → ширина столбца / высота строки; `cells` — `Y.Map` ключ `"<id строки>:<id столбца>"` → `Y.Map` ячейки: `text` (`Y.Text`), `color`, `fontStyle`, `align` (`left|center|right`), `valign` (`top|middle|bottom`), `fill`, `rowSpan`, `colSpan` (у левой верхней ячейки объединения). Объект в ячейке: `parent` = id таблицы, `cell` = ключ ячейки, `x`, `y` — относительно левого верхнего угла ячейки.

На холсте: `[data-object-id][data-type="table"]` (`aria-label="Table"`); ячейки — `[data-cell="<ключ>"]` внутри него (`data-selected="true"` — выделена, `data-focus="true"` — активная); у выделенной незаблокированной таблицы — маркеры границ `[data-handle="col:<id>"]`, `[data-handle="row:<id>"]`. Поле ввода ячейки — `textarea` `aria-label="Table cell"`. Панель выделения (`role="toolbar"` `Selection`): группа `Cells` (`N cell(s)`, списки `Text color`, `Style`, `Align`, `Vertical align`, `Cell fill`), кнопки `Edit cell`, `Merge cells`, `Unmerge cells`, `Rows & columns` → группа `Rows and columns`: `Add row above`, `Add row below`, `Add column left`, `Add column right`, `Delete row`, `Delete column`, поля `Column width`, `Row height`. Выбор при вставке — `role="dialog"` `aria-label="Paste table"`: «Paste R × C table as», кнопки `Table`, `Sticky notes`, `Cancel`.

Известные ограничения:
- Оформление текста — на уровне ячейки, не отдельных символов; высота строки не растёт сама под текст (текст обрезается, строку растягивают маркером или полем `Row height`).
- Копируется таблица целиком, а не диапазон ячеек; вставка из буфера в выделенные ячейки существующей таблицы не делается — внешняя таблица вставляется новой таблицей или стикерами.
- Системная вставка по кнопке `Paste` панели (без события буфера, без HTTPS) по-прежнему берёт только последнюю копию объектов этого браузера — внешнюю таблицу вставляют Ctrl/⌘+V.
- Вложенных таблиц нет; поворота у таблицы нет.
