# T6.2 · Стикеры

Требования: STK-01, STK-02, STK-03, STK-04, STK-05
Ветки: dev/T6.2, qa/T6.2

## Handoff (DEV)

Коммит: 63f153a (карточка — следующим коммитом ветки)
Запуск (из корня репозитория):

```sh
docker compose --project-directory deploy/compose -p <проект> down -v
docker compose --project-directory deploy/compose -p <проект> up --build
```

Переменные — из `deploy/compose/.env.example`, новых нет. Сервер, миграции, HTTP-маршруты и сообщения WebSocket не менялись: всё — в документе Yjs (`objects`). Новых зависимостей нет.

Подготовка данных (как в T6.1):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login` (или форма `/login`), доска — `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.
4. Стикер — инструмент `Sticky note` (клавиша N, закреплён); стопка — инструмент `Sticky stack` (клавиша K, в полном списке `All tools`, по умолчанию не закреплён).

Модель данных стикера (`type: "sticky"`): `text` — `Y.Text` с атрибутами Quill (как у текста T6.1: начертание, ссылки, заголовки, списки); `fill` — цвет; `fontSize` — число или `"auto"` (по умолчанию `"auto"`); `tags` — `Y.Array<string>` без «#» (у нового стикера пустой массив создаётся сразу); `showAuthor` — `false`, если имя автора скрыто (нет поля — показано). Стопка (`type: "stack"`): `fill`, `tags` (`Y.Array<string>`), рамка 200×200, текст пустой.

Что ещё изменилось:
- Стикер стал объектом с форматированным текстом (решение владельца — `Y.Text` с атрибутами): правка — тем же редактором Quill, что и текст T6.1; пока правят стикер, панель `Selection` скрыта (над полем — `Text formatting`), как у текста. `Y.Text.toJSON()` по-прежнему строка.
- Отмена внутри поля (Ctrl/⌘+Z) у текста, документа и стикера: набор и удаление — разные шаги, как в обычном поле браузера (Quill по умолчанию сливал всё за секунду в один шаг; без этого приёмочный тест `CVS-25 keys do not act on the board while typing…` падал на стикере). Тест `richtext/history.test.ts`.
- Копия и вставка объектов переносят теги как `Y.Array`.

Известные ограничения:
- Автоподгон считает каждый клиент по своей отрисовке: при разных системных шрифтах размер у участников может отличаться на 1–2 px.
- В стикере Tab занят STK-04, поэтому отступ пункта списка по Tab в стикере недоступен (в тексте и документе — есть).
- Стопку, вложенную в группу, тянут как группу (как любой объект группы, CVS-17): стикер вытягивается только из стопки верхнего уровня.
- BUG-017 (minor, панель `Text formatting` у верхнего края) не исправлялся — решения владельца о сроке нет.
