## Handoff (DEV)

Коммит: последний коммит ветки `dev/T6.4` (sha — в сообщении статуса и в отчёте DEV)
Запуск: `docker compose -p myboard-dev --project-directory deploy/compose down -v`, затем `docker compose -p myboard-dev --project-directory deploy/compose up --build` (переменные — `deploy/compose/.env.example`). Сервер не менялся, миграций нет.

Подготовка данных (как в T6.1–T6.3):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login`, доска — `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.
4. Линия — инструмент `Line`: клавиша **C** или `All tools` → `Line` (по умолчанию не закреплён, набор T5.4 не менялся). Протяжка по холсту рисует линию; щелчок без протяжки — горизонтальная линия длиной 200 от точки щелчка. В меню холста — пункт `Add line here` (горизонтальная линия центром в точке).

Модель данных (`type: "line"`): `x`, `y` — положение линии; `width`/`height` — 0 (рамка на сцене вычисляется по точкам); `start`, `end` — `{x, y}` относительно `x`, `y` линии, у привязанного конца ещё `object` (id) и `anchor` (`n` | `e` | `s` | `w` — середины сторон рамки объекта); `points` — массив `{x, y}` точек изгиба (относительно линии); `lineStyle` — `straight` | `elbow` | `curved`; `startCap`, `endCap` — `none` | `arrow` | `triangle` | `circle` | `diamond` (новая линия: `none` / `arrow`); `stroke`, `strokeWidth`; `labels` — `Y.Map` id → `Y.Map {text: Y.Text, position (0…1 по длине), orientation: horizontal|along, align: left|center|right, fontFamily, fontSize, color}`.

На холсте: элемент `[data-object-id][data-type="line"]` (`aria-label="Line"`). Нажатия ловит не рамка, а полоса вдоль линии `path[data-testid="line-hit"]` — щёлкать по ней (`getByTestId('line-hit')`); центр рамки диагональной линии может быть мимо линии. Видимая линия — `path[data-testid="line-stroke"]` с `data-line-style`, `stroke`, `stroke-width`, `d` (координаты относительно рамки линии); наконечники — `path[data-testid="line-cap"]` с `data-end="start|end"` и `data-cap`; подписи — `[data-testid="line-label"][data-label-id]` с `data-orientation`, выбранная — `data-active="true"`. У одной выделенной линии вместо рамки — маркеры `[data-handle="line-start"]`, `line-end`, точки изгиба `line-point-<i>`, середины участков `line-add-<i>`. Пока тянут конец, у объекта под ним видны точки привязки `[data-testid="connect-point"]` (выбранная — `data-active="true"`).

Известные ограничения:
- Точки привязки — только середины четырёх сторон рамки объекта (у эллипса и ромба они на контуре, у треугольника верхняя — на вершине); конец встаёт к ближайшей из них.
- Привязать линию к линии или к группе нельзя; к объектам внутри группы — можно.
- Цвет подписи — из палитры, свой цвет подписи не выбирается (свой цвет есть у самой линии).
- При изменении размера нескольких объектов вместе с линией её свободные точки не масштабируются — линия сдвигается вместе с рамкой.
- Одновременная правка одного поля линии (например, перетаскивание одного конца двумя участниками) — последняя запись побеждает; текст подписи сливается по символам.
