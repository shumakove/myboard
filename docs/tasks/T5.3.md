## Handoff (DEV)

Коммит: 57ce4a4 (код и тесты; карточка — следующим коммитом ветки)
Запуск (из корня репозитория):

```sh
docker compose --project-directory deploy/compose -p <проект> down -v
docker compose --project-directory deploy/compose -p <проект> up --build
```

Переменные — из `deploy/compose/.env.example`. Новых переменных, миграций, зависимостей, HTTP-маршрутов и типов сообщений WebSocket нет; сервер не менялся. Всё новое — поля объектов в `objects` документа Yjs.

Подготовка данных (как в T5.2):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login`; доски `POST /api/boards {"title"}` (для CVS-20 — две); открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.

Новые поля объекта сцены (`Y.Map` в `objects`):
- `createdBy`, `createdAt`, `updatedBy`, `updatedAt` — имя и время ISO 8601 (CVS-22); у объектов, созданных до T5.3, их нет («Unknown»);
- `locked: true` — блокировка (CVS-19);
- группа: `type: "group"`, `parent`, `x`, `y`, `z`, `rotation: 0`, `width`/`height` (только на момент создания — рамку группы интерфейс считает по её объектам); объекты группы — `parent: <id группы>`, `x`, `y` относительно группы, `z` среди объектов группы (CVS-17).

Элементы интерфейса (`apps/web/src/scene/`):
- панель «Selection»: кнопки `Arrange` (меню `role="menu"` «Arrange menu»), `Group`, `Ungroup`, `Lock`, `Unlock`, `Delete`, `More` (меню «Object menu» — то же, что правый щелчок по объекту) — показываются, когда действие доступно; для одного выделенного — блок `aria-label="Object info"`: `data-testid="object-created"` / `"object-modified"` с именем и `<time datetime="ISO">`;
- «Arrange menu»: `Align left|center|right|top|middle|bottom` (от 2 незаблокированных), `Distribute horizontally|vertically` (от 3), `Bring to front`, `Bring forward`, `Send backward`, `Send to back`;
- «Object menu»: `Edit text`, `Copy`, `Cut`, `Duplicate`, `Group`/`Ungroup`, `Lock`/`Unlock`, четыре пункта порядка слоёв, `Delete`;
- «Board menu» (правый щелчок по пустому месту): `Paste here` (если в браузере есть копия), `Add … here`, `Select all`, `Unlock all` (если есть заблокированные);
- панель «Tools»: группа «Board actions» — кнопки `Paste` (последняя копия в центр вида) и `Unlock all` (неактивна без заблокированных);
- рамка выделения нескольких объектов: маркеры промежутка `[data-handle="spacing-x"]` (`aria-label="Adjust horizontal spacing"`, середина правой стороны) и `[data-handle="spacing-y"]` (низ); у заблокированного выделения маркеров нет, `data-locked="true"` на рамке;
- объект: `data-locked="true"` и значок замка `data-testid="lock-badge"`; группа — элемент `data-type="group"`, `aria-label="Group"` (невидимый, нажатия проходят к объектам);
- направляющие: `[data-testid="alignment-guide"]` с `data-axis="x|y"` и `data-value` (координата доски), только пока объект тянут;
- клавиши (вне полей ввода): Ctrl/⌘+C, Ctrl/⌘+X, Ctrl/⌘+V, Ctrl/⌘+D.

Известные ограничения:
- Ластика нет до T6.5 — он должен пропускать объекты с `locked` (CVS-19, DRW-03).
- Автора и даты пишет клиент (сервер документ не разбирает — ARCHITECTURE.md, раздел 6), как и `deletedBy` корзины.
- Копия между досками работает в одном браузере: системный буфер + `localStorage`. Пункты меню Paste берут копию из `localStorage` (без HTTPS браузер не даёт читать буфер по кнопке).
- Вставка повторно в ту же точку кладёт копии друг на друга (центр под указателем).
- Объект в заблокированной группе разблокируется только вместе с группой (`Unlock` у группы или `Unlock all`).
- Горячие клавиши группировки, блокировки и слоёв не назначены — это T5.4 (CVS-25).
- Направляющие — только при перемещении (не при изменении размера).
