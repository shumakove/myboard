# T2.2 · Папки и избранное

Требования: BRD-07, BRD-09, BRD-10, BRD-11, BRD-06 (поиск папок, отложенный из T2.1)
Ветки: dev/T2.2, qa/T2.2

## Handoff (DEV)

Коммит: см. последний коммит ветки `dev/T2.2`
Запуск (из корня репозитория):

```sh
docker compose --project-directory deploy/compose -p <проект> down -v
docker compose --project-directory deploy/compose -p <проект> up --build
```

Переменные — из `deploy/compose/.env.example`. Новая миграция `0004` (таблицы `folders`, `favorites`, столбец `boards.folder_id`) применяется при старте API.

Подготовка данных:
1. Администратор: `POST /api/admin/login`, затем `POST /api/admin/users {"name","email","password"}` — пользователи A и B.
2. Пользователь: `POST /api/login` или форма `/login`.
3. Доски: New board на `/` или `POST /api/boards {"title"}`.
4. Папки: кнопка New folder (поле Folder name, Create) или `POST /api/folders {"title", "parent_id"?}`; подпапка — кнопка `+` (имя `New folder in <папка>`) в строке папки.

| Требование | Статус | Где смотреть |
| --- | --- | --- |
| BRD-07 | реализовано | Звезда `Favorite` (`aria-pressed`) в строке All boards и в строке папки дерева; раздел Favorites в боковом списке (`list` «Favorites»), там же звезда убирает. API: `PUT/DELETE /api/boards/{id}/favorite`, `PUT/DELETE /api/folders/{id}/favorite` → `204`; поле `favorite` в `BoardOut` и `FolderOut` |
| BRD-09 | реализовано | Боковой список (`complementary` «Folders and favorites»): New folder, `+` в строке папки — папка внутри; вложенность без ограничения глубины. `GET /api/folders`, `POST /api/folders` → `201 FolderOut {id, parent_id, title, position, favorite, created_at}`; чужой/несуществующий `parent_id` → `404 {"detail":"Folder not found"}` |
| BRD-10 | реализовано | Ручка `Drag <название>` у папок дерева, у досок дерева и у строк All boards. Отпустить на строке папки: верхняя четверть — перед, нижняя — после, середина — внутрь (для доски — вся строка). Свободное место раздела Folders — верхний уровень. API: `PUT /api/folders/{id}/position {"parent_id", "position"}` → `200`, `PUT /api/boards/{id}/folder {"folder_id"}` → `200`. Порядок хранится в `folders.position` (виден после перезагрузки). Вложение в себя или свою дочернюю: `409 {"detail":"A folder cannot be moved into itself or its subfolder"}`, в интерфейсе — тот же текст в `alert` |
| BRD-11 | реализовано | Кнопка с названием папки (`aria-expanded`) сворачивает/разворачивает; содержимое — `list` «Contents of <папка>». Состояние запоминается в браузере (`localStorage`) |
| BRD-06 (папки) | реализовано | Поле Search boards: при запросе появляется `list` «Matching folders» (путь «Work / Projects / Alpha»), нажатие раскрывает папку в дереве и ставит на неё фокус. API: `GET /api/folders?q=` — без учёта регистра, `%`/`_`/`\` буквально |
| Изоляция | реализовано | Чужие папки не видны в `GET /api/folders`; чужая папка/доска как цель или объект переноса и избранного — `404`, неотличимо от несуществующей; все новые маршруты без сессии пользователя — `401` |

Новые эндпоинты: `GET /api/folders`, `POST /api/folders`, `PUT /api/folders/{folder_id}/position`, `PUT|DELETE /api/folders/{folder_id}/favorite`, `PUT /api/boards/{board_id}/folder`, `PUT|DELETE /api/boards/{board_id}/favorite`. В `BoardOut` добавлены `folder_id`, `favorite`. Новых маршрутов интерфейса и сообщений WebSocket нет.

Известные ограничения:
- Переименования и удаления папок, порядка досок внутри папки нет — требований на них нет.

- Доски верхнего уровня в дереве не показываются (они в All boards); фильтра All boards по папке нет.
