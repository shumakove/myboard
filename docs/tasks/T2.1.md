## Handoff (DEV)

Запуск (из корня репозитория):

```sh
docker compose --project-directory deploy/compose -p <проект> down -v
docker compose --project-directory deploy/compose -p <проект> up --build
```

Переменные — из `deploy/compose/.env.example`. Новая миграция `0003` (таблица `boards`) применяется при старте API.

Подготовка данных:
1. Администратор (`ADMIN_EMAIL`/`ADMIN_PASSWORD`): `POST /api/admin/login`, затем `POST /api/admin/users {"name","email","password"}` — пользователи A и B.
2. Пользователь: `POST /api/login {"email","password"}` (cookie `myboard_session`) или форма `/login`.
3. Доски: кнопка New board на `/` или `POST /api/boards {"title": "..."}` (без `title` — «Untitled board»).
4. Старая дата изменения для проверки фильтра: `UPDATE boards SET updated_at = now() - interval '30 days' WHERE id = ...` в контейнере postgres.
