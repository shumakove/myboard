Переменные — из `deploy/compose/.env.example`. Новых переменных, миграций, зависимостей, HTTP-маршрутов и типов сообщений WebSocket нет. Документ доски получил новый корень `settings` (Y.Map) — фон и шаг сетки (вопрос Q-002).

Подготовка данных (как в T4.1–T5.1):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login` → cookie `myboard_session`; доска `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; другой контекст браузера открывает `/b/{token}` и вводит имя. У участника те же инструменты и правки.

Объект сцены в `objects` документа — `Y.Map`: `type` (`sticky` | `shape` | `text`), `parent` (`null` — верхний уровень; координаты дочернего — относительно родителя), `x`, `y`, `width`, `height`, `rotation` (градусы вокруг центра), `z` (целое, новый — поверх), `fill` / `stroke` (стикер, фигура) или `color` / `fontSize` (текст), `text` — `Y.Text`. Объекты JSON (как в тестах T5.1) тоже рисуются и при правке переводятся в `Y.Map`. Корень `settings`: `{background: "#rrggbb", gridStep: 0|10|20|40|80}`, по умолчанию `#fafafa` и 20.

Элементы интерфейса (`apps/web/src/scene/`, `canvas/BoardCanvas.tsx`):
- левая панель `role="toolbar"` «Tools»: кнопки `Select`, `Lasso`, `Sticky note`, `Shape`, `Text` (`aria-pressed` у выбранной); кнопку создания можно перетащить на холст;
- над холстом группа «Board settings»: списки `Background` (Light gray, White, Cream, Mint, Sky, Dark) и `Grid` (Off, 10 px … 80 px); у холста `data-grid-step`, `style.backgroundColor`, `backgroundSize`;
- объект: элемент с `data-object-id`, `data-type`, `aria-label` (Sticky note / Shape / Text), `aria-selected`;
- выделение: `data-testid="selection-frame"`, маркеры `[data-handle="nw|ne|sw|se"]` (`aria-label="Resize se"` …) и `[data-handle="rotate"]` (`aria-label="Rotate"`, только если поворот есть у всех выделенных типов); рамка — `data-testid="selection-marquee"`, лассо — `data-testid="selection-lasso"`;
- панель выделения `role="toolbar"` «Selection» поверх холста слева вверху: «N selected», группа «Keep only» с кнопками `Only sticky notes (2)` / `Only shapes (1)` / `Only texts (1)`, списки свойств `Fill`, `Border`, `Text color`, `Font size` (только общие для выделенных типов; разные значения — `Mixed`), кнопки `Edit text`, `Delete`;
- редактор текста — `textarea` `aria-label="Object text"` поверх объекта; Escape или уход фокуса закрывают;
- контекстное меню `role="menu"`: «Object menu» (`Edit text`, `Delete` / `Delete N objects`), «Board menu» (`Add sticky note here`, `Add shape here`, `Add text here`, `Select all`).

Известные ограничения:
- Типы объектов T5.2 — стикер, фигура (прямоугольник), текст; остальные типы и их оформление — T6.*/T7.*.
- Прилипание — только к сетке; направляющие к соседям (CVS-16) — T5.3. Копирование/вставка объектов доски, порядок слоёв, группы, блокировка — T5.3; отмена — T5.4.
- Выделение участника другим не показывается (требования нет).
- Миникарта не учитывает поворот объектов (рисует их рамку без поворота).
- Контекстное меню на телефоне (долгое касание) не открывается — долгое касание выделяет (MOB-03); действия меню объекта доступны в панели «Selection».
