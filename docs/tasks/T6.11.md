# T6.11 · Реакции, флип-карточки, кубик

Требования: RCT-01, RCT-02, RCT-03, RCT-04, FLP-01, FLP-02, FLP-03, DICE-01, DICE-02, DICE-03
Ветки: dev/T6.11, qa/T6.11

## Handoff (DEV)

Коммит: последний коммит ветки `dev/T6.11`.
Запуск: `docker compose -p myboard-dev --project-directory deploy/compose down -v`, затем `docker compose -p myboard-dev --project-directory deploy/compose up --build` (переменные — `deploy/compose/.env.example`). Миграций и изменений сервера нет: реакция, флип-карточка и кубик — объекты документа Yjs, сервер их не интерпретирует.

Подготовка данных (как в T6.1–T6.10):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login`, доска — `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.
4. Инструменты в `All tools` (можно закрепить, CVS-24): `Flip card` (клавиша **H**), `Dice` (**X**), `Reaction` (**U**). Меню пустого места — `Add flip card here`, `Add dice here`.

Модель данных (объекты `objects`):
- реакция `type: "reaction"` — `parent` (объект, на котором стоит), `x`, `y` относительно него, `width` = `height` (размер), `image` (символ эмодзи из набора), автор — `createdBy`;
- флип-карточка `type: "flipcard"` — `text` (`Y.Text`, лицевая сторона), `backText` (`Y.Text`, оборот), `flipped`, `direction` (`horizontal`/`vertical`), у сторон ключи `frontFill`, `frontFontSize`, `frontFontStyle`, `frontColor`, `frontAlign`, `frontImage` и те же с `back…`; картинка — `data:image/…`;
- кубик `type: "dice"` — `faces` (4, 6, 8, 10, 12, 20), `value` (`null` до броска), `roll` (номер броска), цвет — `fill`.

На холсте:
- реакция — `[data-object-id][data-type="reaction"]`, `aria-label="<Название> by <имя>"` (например `Rocket by Ann`); по наведению (и у выделенной) видна подсказка `.reaction-author` (`role="tooltip"`) с тем же текстом. Черновик, пока кнопку держат, — `[data-testid="reaction-draft"]` (`data-size` — текущий размер);
- флип-карточка — `[data-type="flipcard"]` с `data-side="front|back"`, стороны — `.flip-face[data-side]`, `.flip-inner[data-direction]`; кнопка переворота в правом верхнем углу — `button[data-flip-toggle]` `aria-label="Flip card"` (видна по наведению, у выделенной, на сенсорном экране — всегда); поле правки — textarea `aria-label="Flip card side text"`;
- кубик — `[data-type="dice"]`, `aria-label="Dice d<N>: <значение>|not rolled"`, значение — `[data-testid="dice-value"]` (до броска «–»), подпись `d<N>`.

Панель выделения (`role="toolbar"` `Selection`):
- группа `Flip card`: `Flip` (у нескольких — `Flip all (N)`); у одной карточки — подпись `Front side`/`Back side` (показанная сторона), списки `Flip direction` (Horizontal/Vertical), `Side color`, `Font size`, `Style` (Regular, Bold, Italic, Bold italic, Underline, Strikethrough), `Text color`, `Align`, кнопки `Add image`/`Replace image` (файл изображения, input `aria-label="Side image"`), `Remove image`; `Edit text` — текст показанной стороны;
- группа `Dice`: `Roll` (у нескольких — `Roll all (N)`), список `Faces`, при двух и более кубиках — `Sum: N` (`output.dice-sum`); цвет — общий список `Fill` и `Custom color`.
- инструмент Reaction: панель `role="toolbar"` `Reactions` со вкладками `Recent`, `Emotions`, `Votes`, `Stamps`; кнопки изображений — `<Название> reaction` (`aria-pressed` у выбранного).

Известные ограничения:
- Картинка стороны карточки хранится в документе (data URL, до 640 px), а не в `media` — модуль `media` (T7.1) ещё не реализован; вопрос владельцу Q-006 (не блокирует).
- Текст стороны флип-карточки — простой: размер и форматирование задаются для всей стороны, а не для фрагментов.
- Реакцию нельзя поставить на пустое место и линию; нажатие на объект в группе ставит её на сам объект, а не на группу.
- Изображения реакций — эмодзи системного шрифта; вид зависит от ОС.
