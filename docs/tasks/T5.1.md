## Handoff (DEV)

Коммит: см. последний коммит ветки `dev/T5.1`
Запуск (из корня репозитория):

```sh
docker compose --project-directory deploy/compose -p <проект> down -v
docker compose --project-directory deploy/compose -p <проект> up --build
```

Переменные — из `deploy/compose/.env.example`. Новых переменных, миграций, зависимостей и сообщений WebSocket нет. Изменение HTTP-контракта: в схеме `SharedBoard` (`GET /api/share/{token}`, `POST /api/share/{token}/join`) добавлено поле `id` — uuid доски (ключ запомненного вида у участника, CVS-05); `apps/web/openapi.json` и `src/api/schema.d.ts` обновлены.

Подготовка данных (как в T4.1–T4.3):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login` → cookie `myboard_session`; доска `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; другой контекст браузера открывает `/b/{token}` и вводит имя.
4. Объекты для миникарты (CVS-01, CVS-04): инструментов создания ещё нет (T5.2), миникарта читает объекты верхнего уровня из корня `objects` документа Yjs — JSON или `Y.Map` с числовыми `x`, `y`, `width`, `height` (например, `{"type":"sticky","x":5000000,"y":-3000000,"width":200,"height":200}`), записанные обновлением `sync Update` по `/api/ws`. На самом холсте объекты пока не рисуются — сцена в T5.2.

Элементы интерфейса (`apps/web/src/canvas/`, `collab/BoardWorkspace.tsx`):
- холст `data-testid="board-canvas"`, слой доски — его первый дочерний элемент, `style.transform = scale(zoom) translate(-x px, -y px)` (x, y — центр вида в координатах доски);
- панель над холстом `role="toolbar"` «View»: кнопки «Zoom out» / «Zoom in», текст масштаба `aria-label="Zoom level"` (например, `125%`), список `Mouse wheel` (`zoom` — «Zooms», `scroll` — «Scrolls (Ctrl/⌘ + wheel zooms)»);
- миникарта `role="img"` «Minimap» (`data-testid="minimap"`) в правом нижнем углу холста, объекты — `rect.minimap-object`, рамка вида — `data-testid="minimap-view"`;
- `localStorage`: `myboard.camera.<board_id>` → `{x, y, zoom}`, `myboard.wheelMode` → `zoom | scroll`.

- Объекты на холсте не рисуются и не создаются — сцена и инструменты в T5.2; миникарта уже читает `objects`.
