# T6.1 · Текст и документ

Требования: TXT-01, TXT-02, TXT-03, TXT-04, TXT-05, TXT-06, TXT-07, TXT-08 (+ COL-01 для текста; BUG-010 по решению владельца)
Ветки: dev/T6.1, qa/T6.1

## Handoff (DEV)

Коммит: 8a049f9 (код, тесты, `docs/decisions.md`; карточка — следующим коммитом ветки)
Запуск (из корня репозитория):

```sh
docker compose --project-directory deploy/compose -p <проект> down -v
docker compose --project-directory deploy/compose -p <проект> up --build
```

Переменные — из `deploy/compose/.env.example`, новых нет. Сервер, миграции, HTTP-маршруты и сообщения WebSocket не менялись: всё — в документе Yjs (`objects`). Новая npm-зависимость интерфейса — `quill@^2.0.3` (`apps/web/package.json`, lock обновлён).

Подготовка данных (как в T5.3–T5.5):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login` (или форма `/login`), доска — `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.
4. Текст — инструмент `Text` (клавиша T); документ — инструмент `Document` (клавиша D; в полном списке `All tools`, по умолчанию не закреплён — набор T5.4 из пяти инструментов не менялся). Щелчок инструментом ставит объект и сразу открывает редактор; потом — двойной щелчок или `Edit text` в панели `Selection`.

Модель данных: `text` объекта — `Y.Text` с атрибутами форматирования (модель Quill). Символы: `bold`, `italic`, `underline`, `strike`, `link`. Строка (атрибут на её `\n`): `header` 1–3, `list` = `bullet` | `ordered` | `checked` | `unchecked`, `indent` 1–8. Документ (`type: "document"`) — то же плюс вставки `{divider: true}` и `{objectLink: "<id объекта>"}`. `Y.Text.toJSON()` по-прежнему простая строка (поиск, прежние проверки). Свойства блока — поля объекта: `fontFamily` (`sans`|`serif`|`mono`|`hand`), `fontSize`, `color`, `fontStyle` (`normal`|`bold`|`italic`|`bold-italic`|`underline`|`strike`), `align` (`left`|`center`|`right`|`justify`), `lineHeight`, `background` (`transparent` — без фона).

Что ещё изменилось:
- Пока правят текст или документ, панель `Selection` скрыта (над полем — панель редактора `Text formatting`, панель выделения её закрывала бы у объектов вверху холста). Для стикера и фигуры (простое поле) — как раньше.
- Текстовый блок при своей правке принимает высоту содержимого, документ только растёт; вставленный HTML — высота по числу строк.
- Решение владельца по тегам (CVS-08): `tags` — `Y.Array<string>`, тег без «#» — записано в `docs/decisions.md`.

Известные ограничения:
- Высота блока обновляется при своей правке текста; смена размера шрифта в панели без правки высоту не пересчитывает (текст виден поверх рамки).
- Меню «/» и панель редактора лежат в слое доски (масштаб компенсирован): у нижнего края холста меню может уйти под миникарту.
- Отметка о том, кто сейчас печатает в тексте (курсоры в тексте), не делалась — в требованиях её нет.
