# T6.3 · Фигуры и BPMN

Требования: SHP-01, SHP-02, SHP-03, SHP-04
Ветки: dev/T6.3, qa/T6.3

## Handoff (DEV)

Коммит: e3e827f (карточка — следующим коммитом ветки)
Запуск (из корня репозитория):

```sh
docker compose --project-directory deploy/compose -p <проект> down -v
docker compose --project-directory deploy/compose -p <проект> up --build
```

Переменные — из `deploy/compose/.env.example`, новых нет. Сервер, миграции, HTTP-маршруты и сообщения WebSocket не менялись: фигуры — объекты документа Yjs (`objects`). Новых зависимостей нет.

Подготовка данных (как в T6.1/T6.2):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login` (или форма `/login`), доска — `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.
4. Фигуры — инструмент `Shape` (клавиша S, закреплён).

Модель данных фигуры (`type: "shape"`): `shape` — вид (id из каталога `apps/web/src/scene/shapes.ts`; нет поля или неизвестный — `rectangle`); `marker` — маркер BPMN (только у видов с маркерами; нет поля или чужой маркер — первый маркер вида); `fill` (цвет или `"transparent"`), `stroke`, `strokeWidth` (число, 0 — без обводки), `radius` (число), `fontSize`, `color`, `align`, `lineHeight`; `text` — `Y.Text` (простой текст, как раньше). Новая фигура получает размер и оформление своего вида (например, `connector` 70×70, `bpmn-end` 60×60 с `strokeWidth: 4`, `marker: "none"`).

На холсте элемент фигуры — `[data-object-id]` с `data-type="shape"`, `aria-label="Shape"`, `data-shape="<вид>"`, у видов BPMN с маркерами — `data-marker="<маркер>"`; внутри — `svg[data-testid="shape-outline"]` (первый `path` — контур: атрибуты `fill`, `stroke`, `stroke-width`; скругление — команды `Q` в `d`), значки маркера — `g[data-testid="shape-marker"]`, текст — `.shape-text`.

Что ещё изменилось:
- Фигура больше не рисуется фоном и рамкой элемента: `background-color` и `border-color` элемента фигуры пусты, цвета — на контуре SVG (стикер, текст и документ — как раньше).
- Фигуры, созданные до T6.3 (без `shape`), показываются прямоугольником; их цвета и текст не меняются.
- `stickyColor` (цвет следующего стикера) принимает и свой цвет `#rrggbb`.

Известные ограничения:
- SHP-04 для линии: категория `line` хранится и отделена от остальных, но палитры линии ещё нет — линии появятся в T6.4 (зависит от T6.3). Сценарий плана «недавние цвета стикера не появляются в палитре линии» проверяем после T6.4; сейчас — только раздельность категорий текст/стикер/фигура.
- У фигуры BPMN один маркер (поле `marker`): тип задачи и маркер цикла одновременно не задаются.
- Текст фигуры — простой (без форматирования внутри строки, как раньше); выравнивание и интервал — на весь текст.
- Длинные слова в узкой области текста (Cross, Connector) переносятся по буквам.
- Группа `Custom color` и `Text style` остаются открытыми при смене выделения.
