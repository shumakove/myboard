## Handoff (DEV)

Коммит: последний коммит ветки `dev/T6.6` (код — 9315f05, затем эта карточка)
Запуск: `docker compose -p myboard-dev --project-directory deploy/compose down -v`, затем `docker compose -p myboard-dev --project-directory deploy/compose up --build` (переменные — `deploy/compose/.env.example`). Миграций и изменений сервера нет: фрейм — объект документа Yjs, сервер его не интерпретирует.

Подготовка данных (как в T6.1–T6.5):
1. Администратор: `POST /api/admin/login`, `POST /api/admin/users {"name","email","password"}`.
2. Владелец: `POST /api/login`, доска — `POST /api/boards {"title"}`; открыть `/boards/{id}`.
3. Участник: `GET /api/boards/{id}/share` → `token`; открыть `/b/{token}` и ввести имя.
4. Инструмент `Frame` — в `All tools` (можно закрепить, CVS-24), клавиша **F**; щелчок по холсту ставит фрейм 640×480 центром в точке; меню пустого места — `Add frame here`.

Модель данных (`type: "frame"`): `x`, `y`, `width`, `height` (поворота нет), `z`; `appearance` — `fill` | `border` | `outline`; `fill` — цвет; `keepRatio` (bool, FRM-03); `contentHidden` (bool, FRM-04); `lockContent` (bool, FRM-05; без поля — `true`); `locked`, поля автора и дат. Дети фрейма — объекты с `parent` = id фрейма и `x`, `y` относительно его левого верхнего угла.

На холсте: `[data-object-id][data-type="frame"]` (`aria-label="Frame"`), атрибуты `data-appearance`, `data-content-hidden="true"` (когда скрыто), `data-locked`. Объекты фрейма — отдельные элементы `[data-object-id]` поверх него.

| FRM-01 | реализовано | `/boards/{id}`, `/b/{token}`. Объект попадает во фрейм, когда его центр оказывается внутри рамки фрейма после перетаскивания, постановки инструментом (щелчок, перетаскивание кнопки, `Add … here`) или штриха пера/маркера; выходит, когда центр снаружи. Новый фрейм забирает объекты верхнего уровня, лежащие в нём целиком, и встаёт под ними. Объекты фрейма двигаются вместе с ним (и у второго участника — правка документа по `sync`). Щелчок по объекту во фрейме выделяет объект; рамка/лассо выбирают и объекты внутри фреймов. Удаление/копирование фрейма — вместе с содержимым. Линия: инструмент `Line`, конец над пустой частью фрейма привязывается к фрейму (CVS-26), над объектом внутри — к объекту. Сами не переходят: фреймы, линии, заблокированные объекты, объекты внутри групп (переходит группа). |
| FRM-02 | реализовано | Выделить фрейм → панель выделения: `Frame style` (`Fill` / `Border only` / `No background`) и `Frame color` (палитра); `Custom color` → поле `Custom frame color`. Fill — фон цветом; Border only — граница цветом 3 px, фон белый; No background — граница цветом, фон прозрачный. Толкование видов — Q-004 (не блокирует). |
| FRM-03 | реализовано | Один выделенный незаблокированный фрейм: переключатель `Keep proportions` (`role="switch"`). Включён — угловые маркеры `[data-handle=nw/ne/sw/se]` меняют размер в прежнем соотношении сторон; выключен — стороны независимо. При изменении размера объекты внутри остаются на месте доски. |
| FRM-04 | реализовано | Выделить фрейм → `Hide content` / `Show content` (и в меню объекта); кнопка есть и у заблокированного фрейма. Скрытое содержимое не рисуется у всех участников (поле `contentHidden`), на фрейме — пометка `Content hidden`; скрытые объекты не выделяются, не ищутся, не стираются; во фрейм со скрытым содержимым объекты не попадают. |
| FRM-05 | реализовано | Выделение с фреймом → `Lock` раскрывает группу `role="group"` `aria-label="Lock frame"`: «Lock what?», кнопки `Frame only` и `Frame and content`. В контекстном меню вместо `Lock` — `Lock frame only` и `Lock frame and content`. Frame only: фрейм не двигается и не меняет размер, объекты внутри правятся, двигаются, выходят из фрейма и попадают в него. Frame and content: заблокировано и содержимое (замок на объектах), новые объекты во фрейм не попадают. Без фреймов `Lock` блокирует сразу, как раньше. |

Известные ограничения:
- Вложенных фреймов нет: фрейм сам в другой фрейм не попадает (может быть в группе).
- Линии в фреймы не переходят: их положение задают концы; линия, привязанная к объектам фрейма, следует за ними.
- При масштабе нескольких выделенных объекты внутри выделенного фрейма едут вместе с ним, но не масштабируются.
- Названия (заголовка) у фрейма нет — требования его не называют; страницы PDF по фреймам — FRM-06, задача T10.2.
